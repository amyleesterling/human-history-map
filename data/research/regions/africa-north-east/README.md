# North and Northeast Africa research

Status: first source-checked thematic batch, awaiting independent review. This is not complete coverage of the region or of any polity's changing borders. Asia is assigned to QWEN; no Asia-centered polity is owned here.

Nine runtime cards cover Egypt, Kush, Aksum, the Carthaginian state, Numidia, Almoravids, Almohads, Hafsids and Marinids. Garamantes and Zagwe cards are staged because appropriate indexed identities are absent. Each entity folder contains evidence.json with claim paths, exact source sections, chronology caveats and remaining work.

The imported carthaginian-empire and carthage records are successive labels for one civilization. They are not counted twice. A canonical-identity change should preserve both existing URLs and border references. The later carthage ID still needs routing to the shared researched material.

No new borders are supplied. UNESCO heritage property boundaries identify protected archaeological sites, not state territory. Cards remain whole-history introductions until the application supports dated claim intervals.
